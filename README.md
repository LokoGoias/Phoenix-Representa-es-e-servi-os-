# Phoenix Representações e Serviços

Página institucional da **Phoenix Representações e Serviços** para apresentação da empresa, serviços e canais de contato.

## Descrição

Este repositório contém uma landing page responsiva com foco em:

- apresentação da empresa;
- divulgação dos serviços de desenvolvimento de apps e sites;
- captação de contatos via formulário;
- contato rápido via WhatsApp e e-mail.

> Descrição do repositório: `Página para apresentação de informações da empresa e contato`.

## Publicação com GitHub Pages

1. Acesse **Settings > Pages** no repositório.
2. Em **Build and deployment**, selecione:
   - **Source**: Deploy from a branch
   - **Branch**: `main` / `/ (root)`
3. Salve as configurações e aguarde a publicação.
